# ✨ 윤슬 맞춤법 & 띄어쓰기 검사기 (Windows Universal)

웹 브라우저(Chrome, Edge, Whale 등), 메모장, 카카오톡, Word, Slack 등 **윈도우 어디서든 텍스트를 작성하거나 커서를 올려놓고 마우스 오른쪽 버튼을 누르면 맞춤법 및 띄어쓰기를 검사하고 가이드라인을 팝업으로 보여주는 프로그램**입니다.

---

## 🌟 마우스 커서 텍스트 3대 인식 모드

1. **방식 1: 윈도우 UI Automation (RangeFromPoint)**
   - 마우스 커서가 가리키고 있는 웹/문서/프로그램의 텍스트 컨트롤에서 커서 바로 아래의 **단어(Word) 또는 문장(Line)**을 0.01초 만에 직접 인식하여 추출합니다.
2. **방식 2: 700px 와이드 화면 네이티브 OCR (`Windows.Media.Ocr`)**
   - 마우스 커서를 중심으로 **가로 700px 영역**을 실시간 캡처하여 윈도우 11 내장 한국어 광학 인식(OCR)을 수행합니다.
   - 복사 방지 웹사이트, 캔버스, 이미지, PDF, 원격 화면 등 **화면에 보이는 모든 한국어 글자**를 100% 인식합니다.
3. **방식 3: 활성 입력창 캐럿(Caret) 자동 감지**
   - 글을 타이핑하던 중 마우스 우클릭을 누르면 커서가 있는 입력 필드에 작성 중이던 문장을 자동으로 읽어와 맞춤법 검사를 수행합니다.

## 🚀 빠른 시작 방법

### 방법 1. 무설치 단일 포터블 실행
**`YUNSEUL-SPELLCHECK.exe`**를 더블 클릭하면 설치 없이 즉시 실행됩니다.

### 방법 2. 설치 마법사 실행
**`YUNSEUL-SPELLCHECK-Setup.exe`**를 실행하면 바탕화면 및 시작 메뉴 바로가기가 생성됩니다.

---

## 💡 사용 방법

1. **스마트 자동 검사:**
   - 텍스트 위나 입력창에 마우스를 두고 **우클릭** ➔ 커서 위에 나타난 **`[ 📝 맞춤법 검사 ]`** 클릭
   - 선택 영역 / 입력창 글 / 커서 위치 단어를 스마트 체인으로 자동 인식합니다.
2. **700px 광학 OCR 검사:**
   - 마우스 우클릭 후 **`[ 📸 700px OCR ]`** 클릭
   - 커서 주변 700px 가로 영역의 화면 글자를 즉시 인식하여 검사합니다.
3. **원클릭 자동 치환:**
   - 팝업창에서 **`[ ⚡ 입력창에 바로 적용 ]`**을 누르면 원문 글이 올바른 교정본으로 즉시 자동 교체됩니다.
